# K2 Family Office ガイド写真の設計意図

2026年11月27日　ガイド1・2・3 プレビュー用

## 共通の写真ルール

- メディアトップのスライド写真を人物と光の基準にする。中心人物は若々しい40代の男性とし、家族が登場する場面でも同じ家族に見えるようにする。
- 顔を正面から大きく見せず、横顔、後ろ姿、手元、会話中の自然な動作で人物像を伝える。
- 明るい自然光、温かい木、緑、街、海の色を使う。記事中の写真に一律の暗いフィルターをかけない。
- 写真は隣の文章の内容を見せるために置く。同じ風景を枚数だけ増やさず、人物の行動、場所、距離を変える。
- 図は判断の関係を説明し、写真はその判断を自分や家族の生活として想像できるようにする。
- ガイド1のCASE 01・02・03は、指定済みの写真を維持する。

## Guide 1｜事業と資産を、家族の未来につなぐ

| 掲載箇所 | 見せる場面 | 写真を置く理由 |
| --- | --- | --- |
| 表紙 | C案：家族が同じ書斎の机を囲む場面（採用） | 事業・資産・教育と家族の希望を、同じ空間で一緒に考えることを見せる。 |
| 家族のための全体設計・1 | 明るい仕事場で経営者が事業の現場を見渡す場面 | 「事業」を会社での具体的な活動として見せ、中央の資産相談写真と場面・距離を変える。 |
| 家族のための全体設計・2 | 資産と将来支出を検討する手元 | 近景で「資産」を見せ、左の空間写真・右の家族写真と距離を変える。 |
| 家族のための全体設計・3 | 家族が外で過ごす時間 | 事業と資産の先にある「家族の暮らし」を視覚的な結論にする。 |
| 経営者に必要な理由・1 | 経営者が私的なオフィスで経営計画を見直す場面 | 会社には計画があるという本文を示しつつ、家族の計画へ視点を移すために一人の姿を置く。 |
| 経営者に必要な理由・2 | 夫婦が子どもの将来を話す場面 | 会社の計画と家族の計画は別々に考えられがちだと示す。 |
| 資産よりどう生きるか | 海辺のテラスで家族がバーベキューを楽しむ時間 | お金の管理が目的ではなく、選べる未来の暮らしに結びつくことを見せる。 |

### Guide 1 表紙の比較案

3案とも本文や見出しを変えず、写真だけを比較した。C案を採用し、標準表示に設定した。

| 案 | 写真の主役 | 伝える意味 | 留意点 |
| --- | --- | --- | --- |
| A：私的な対話 | 私的な執務室で向き合う夫婦 | 本人と家族の希望を一緒に考えるというGuide 1の出発点。Private Officeの空間も伝わる。 | 写真は静かなため、見出しと本文で判断の対象を明確にする。 |
| B：思考の空間 | 人物のいない木質の私的な執務室 | 守られた場所で人生全体を設計する知的な印象。 | 家族の存在は写真だけでは弱い。 |
| C：家族の書斎 | 親子が同じ机を囲む場面 | 事業・資産・教育が一つの場につながる様子。 | 家庭的に寄りすぎないよう、建築と落ち着いた光を主役にする。 |

## Guide 2｜日本を出発点に、世界の選択肢を比べる

| 掲載箇所 | 見せる場面 | 写真を置く理由 |
| --- | --- | --- |
| 表紙 | 東京湾を見渡すテラスに立つ家族（旧Guide 1表紙） | 現在の暮らしを出発点として、家族で世界の選択肢を考える場面を示す。 |
| 導入 | 東京で家族と歩く男性 | 日本での生活を出発点とし、現在の選択も尊重する。 |
| 日本だけが前提ではない・日本 | 日本の通学路を歩く家族 | 身近な生活環境を具体的に示す。 |
| 日本だけが前提ではない・世界 | パリの生活道路を歩く家族 | 同じ家族に別の生活の可能性があると一目で伝える。 |
| OPTION 01 | 海外の相手と事業について対話する男性 | 市場の広がりを風景だけでなく事業上の行動で見せる。 |
| OPTION 02 | 日本と海外の資産を一つの机で比べる場面 | 似た机の写真を2枚並べず、1枚で資産を比較する行為を伝える。 |
| OPTION 03 | パリの市場、子どもの通学、現地の博物館での学び | 住まいの写真だけでは伝わらない生活と教育の質感を見せる。 |
| まとめ | 世界を知ったうえで日本または海外を選ぶ家族 | 「海外移住が答え」ではなく、自分の意思で選ぶという結論につなぐ。 |

## Guide 3｜対話を、優先順位と実行時期の設計に変える

| 掲載箇所 | 見せる場面 | 写真を置く理由 |
| --- | --- | --- |
| 表紙 | 東京を見渡す明るい仕事場で対話する場面 | 情報を並べる段階から、本人と家族の判断を設計する段階への転換を示す。 |
| 人生全体を見る視点・1 | 事業の対話 | 事業の判断を示す。 |
| 人生全体を見る視点・2 | 資産資料を指す手元 | 資産の判断を示し、1枚目と被らせない。 |
| 人生全体を見る視点・3 | 家族が屋外を歩く姿 | 本人と家族の希望を判断の中心に置く。 |
| 日本と世界での経験・日本 | 東京で協働する場面 | 日本で蓄積した経験を、場所と人の関係で見せる。 |
| 日本と世界での経験・世界 | 海外の街で人と交わる場面 | 世界での経験が視点を広げることを見せる。 |
| 判断のタイミング | ペンを持ち、予定や計画について話す場面 | 「何を決めるか」と「いつ実行するか」を同時に考える姿を示す。 |
| 終章 | 家族がこれからの場所や暮らしを話す場面 | 判断の先にある未来を示し、Guide 1のバーベキューやGuide 2の街歩きと絵を変える。 |

これらはガイド本文の理解を助けるプレビュー用のビジュアルであり、本文の原稿や指定済みのCASE写真は変更していない。Guide 3の創業者の経験に添えた写真は、本人の記録写真ではなくイメージ写真として扱う。
